# Healed Fast — 21-Day Guide

Installable web app (PWA) for a 21-day alkaline eating → herbs → juice/water fast plan.

- Open the GitHub Pages link on your phone, then **Share → Add to Home Screen** (iPhone) or **Install app** (Android).
- Works offline after the first load. Progress is stored on the device only.
- **Today → Add reminders to calendar** creates calendar alarms for every step from your chosen day 1.

Not medical advice. Get baseline bloods before starting and stop if you feel faint, have palpitations or confusion.
